# WSL 代理配置说明

## 代理信息

- **代理地址**: `http://127.0.0.1:7897`
- **代理来源**: Windows 系统代理（自动继承到 WSL）
- **代理速度**: ~436 KB/s（测试值）

## 已配置的代理设置

### 1. Git 代理配置

```bash
# 已配置 Git 使用代理
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897
```

**验证配置**：

```bash
git config --global --list | grep proxy
```

**测试连接**：

```bash
git ls-remote https://github.com/emscripten-core/emsdk.git HEAD
```

### 2. 环境变量代理配置

已在 `~/.bashrc` 中添加：

```bash
export HTTP_PROXY=http://127.0.0.1:7897
export HTTPS_PROXY=http://127.0.0.1:7897
export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897
```

**生效方式**：

```bash
source ~/.bashrc
```

**验证环境变量**：

```bash
env | grep -i proxy
```

### 3. Mise 代理配置

Mise 会自动使用环境变量中的代理设置，无需额外配置。

## 使用代理运行 mise setup

```bash
# 确保环境变量已加载
source ~/.bashrc

# 运行 setup
cd /opt/poe/poe1-pob-web
mise run setup
```

## 代理速度测试

```bash
# 测试 GitHub 下载速度
curl -o /dev/null -s -w 'Speed: %{speed_download} bytes/sec\n' https://github.com

# 测试代理连接
curl -v --connect-timeout 10 https://github.com 2>&1 | grep "Connected"
```

## 常见问题

### Q: 代理配置后还是慢？

A: 可能原因：

1. 代理服务器带宽限制
2. GitHub 服务器限速
3. 网络波动

**解决方案**：

- 尝试更换代理节点
- 使用 GitHub 镜像（但可能不稳定）
- 手动下载大文件

### Q: 如何取消代理配置？

**取消 Git 代理**：

```bash
git config --global --unset http.proxy
git config --global --unset https.proxy
```

**取消环境变量代理**：

```bash
# 编辑 ~/.bashrc，删除以下行：
export HTTP_PROXY=http://127.0.0.1:7897
export HTTPS_PROXY=http://127.0.0.1:7897
export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897

# 重新加载配置
source ~/.bashrc
```

### Q: 如何查看当前代理状态？

```bash
# 查看 Git 代理配置
git config --global --list | grep proxy

# 查看环境变量
env | grep -i proxy

# 测试代理连接
curl -I https://www.google.com
```

## 代理配置文件位置

- **Git 配置**: `~/.gitconfig`
- **环境变量**: `~/.bashrc`
- **Windows 系统代理**: 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`
