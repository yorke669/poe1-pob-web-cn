# 功能与代码修改总结

## 1. 已实现功能

### 1.1 前端悬浮测试工具

在 PoB 页面上新增一个悬浮球入口：

- 默认显示为一个蓝色球形按钮；
- 支持点击展开 / 收起；
- 支持拖动位置；
- 展开后显示「PoB 测试工具」面板；
- 面板采用可扩展结构，后续可以继续添加测试功能。

当前面板结构：

```text
PoB 测试工具
├─ 左侧功能区
│  ├─ 装备对比
│  ├─ 当前属性
│  └─ 后续功能占位
└─ 右侧内容区
   ├─ 参数区
   ├─ 执行按钮
   └─ 结果区
```

### 1.2 当前属性读取

面板中保留「当前属性」功能：

- 点击「获取计算结果」；
- 调用 `driver.getBuildStats()`；
- 从 Lua 侧读取 `build.calcsTab.mainOutput`；
- 返回 JSON 并展示；
- 支持 `Copy JSON` 复制原始数据。

### 1.3 装备对比功能

新增「装备对比」功能，用于获取类似 PoB tooltip 红框中的增减数据。

参数：

- `槽位名`：例如 `Weapon 2`、`Helmet`、`Body Armour`、`Ring 1`；
- `新物品文本`：可选，粘贴 PoB 物品文本；
- `新物品文本` 留空时，表示移除当前槽位装备；
- `新物品文本` 有值时，表示把该槽位装备替换成新物品。

调用流程：

```text
前端「获取装备对比」
  → driver.getItemCompareStats(slotName, itemRaw?)
  → worker.getItemCompareStats(slotName, itemRaw?)
  → C: get_item_compare_stats(slot_name, item_raw)
  → Lua: getItemCompareStats(slotName, itemRaw)
  → build.calcsTab:GetMiscCalculator()
  → 计算替换/移除后的 output
  → 对比 build.displayStats
  → 返回 JSON
```

返回数据包含：

```json
{
  "slotName": "Weapon 2",
  "mode": "remove",
  "changes": [
    {
      "stat": "LightningResist",
      "label": "闪电抗性",
      "before": 75,
      "after": 70,
      "diff": -5,
      "percent": null,
      "positive": false,
      "lowerIsBetter": false,
      "text": "-5% 闪电抗性"
    }
  ]
}
```

### 1.4 对比查看模式

装备对比结果区新增两种查看模式：

| 模式 | 说明 |
|---|---|
| `对比查看` | 表格形式展示，方便人看 |
| `原始 JSON` | 展示完整原始 JSON，方便调试 / 二次处理 |

对比查看表格列：

```text
属性 | 之前 | 之后 | 变化
```

变化颜色：

- 绿色：正向提升；
- 红色：负向下降。

`Copy JSON` 始终复制原始 JSON。

## 2. 涉及修改的代码

### 2.1 `packages/driver/src/js/overlay/FloatingStatsButton.tsx`

新增文件，负责悬浮球和测试工具面板。

主要内容：

- `BALL_SIZE = 56`：球形入口尺寸；
- 支持拖动和点击展开 / 收起；
- 左侧功能导航：`装备对比`、`当前属性`；
- 右侧根据 `activeTool` 切换参数区；
- `runTool()` 根据当前功能调用：
  - `onGetStats()`；
  - `onGetItemCompareStats(slotName, itemRaw)`；
- `CompareResultView`：装备对比的人类可读表格；
- `原始 JSON` 模式和 `Copy JSON`。

### 2.2 `packages/driver/src/js/overlay/OverlayContainer.tsx`

接入悬浮工具组件。

主要修改：

- 引入 `FloatingStatsButton`；
- `OverlayContainerProps` 增加：

```ts
onGetStats?: () => Promise<string>;
onGetItemCompareStats?: (slotName: string, itemRaw?: string) => Promise<string>;
```

- 渲染悬浮工具：

```tsx
{onGetStats && onGetItemCompareStats && (
  <FloatingStatsButton
    onGetStats={onGetStats}
    onGetItemCompareStats={onGetItemCompareStats}
  />
)}
```

### 2.3 `packages/driver/src/js/driver.ts`

在主线程 `Driver` SDK 层暴露能力。

主要修改：

- 新增：

```ts
async getBuildStats(): Promise<string>
async getItemCompareStats(slotName: string, itemRaw = ""): Promise<string>
```

- `overlayManager.render(...)` 首次渲染时传入：

```ts
onGetStats: () => this.getBuildStats(),
onGetItemCompareStats: (slotName, itemRaw) => this.getItemCompareStats(slotName, itemRaw),
```

- `updateOverlayWithTransform()` 更新时也继续传入这两个回调，避免状态刷新后丢失功能。

### 2.4 `packages/driver/src/js/worker.ts`

在 Worker 层绑定 Wasm C 导出函数。

主要修改：

- `Imports` 类型增加：

```ts
getBuildStats: () => string;
getItemCompareStats: (slotName: string, itemRaw: string) => string;
```

- `DriverWorker` 新增：

```ts
async getBuildStats(): Promise<string>
async getItemCompareStats(slotName: string, itemRaw = ""): Promise<string>
```

- `resolveImports()` 增加 `cwrap`：

```ts
getBuildStats: module.cwrap("get_build_stats", "string", []),
getItemCompareStats: module.cwrap("get_item_compare_stats", "string", ["string", "string"]),
```

### 2.5 `packages/driver/src/c/driver.c`

在 C / Wasm 边界新增导出函数。

主要修改：

- 新增静态缓存：

```c
static char *s_build_stats = NULL;
static char *s_item_compare_stats = NULL;
```

- 新增：

```c
EMSCRIPTEN_KEEPALIVE
const char* get_build_stats()
```

调用 Lua 全局 `getBuildStats()`，返回 JSON 字符串。

- 新增：

```c
EMSCRIPTEN_KEEPALIVE
const char* get_item_compare_stats(const char *slot_name, const char *item_raw)
```

调用 Lua 全局 `getItemCompareStats(slotName, itemRaw)`，返回 JSON 字符串。

### 2.6 `packages/driver/boot.lua`

在 Lua 主状态中实现数据读取和对比计算。

主要修改：

#### `getBuildStats()`

读取当前构筑属性：

- 获取 `mainObject.main.modes["BUILD"]`；
- 读取 `build.calcsTab.mainOutput`；
- 遍历 `build.displayStats` 和 `build.extraSaveStats`；
- 返回 JSON。

#### `getItemCompareStats(slotName, itemRaw)`

读取装备替换 / 移除后的增减数据：

- 获取 `build.itemsTab`；
- 校验槽位是否存在；
- `itemRaw` 为空：`repItem = nil`，表示移除当前槽位装备；
- `itemRaw` 不为空：`new("Item", itemRaw)` 创建新物品，并执行 `BuildAndParseRaw()`；
- 调用 `build.calcsTab:GetMiscCalculator()` 获取当前快照和计算函数；
- 调用：

```lua
calcFunc({ repSlotName = slotName, repItem = repItem })
```

- 遍历 `build.displayStats`，计算：

```lua
diff = compareOutput[stat] - baseOutput[stat]
```

- 生成 `before`、`after`、`diff`、`percent`、`positive`、`text` 等字段；
- 返回 JSON。

#### JSON 序列化

新增最小化 JSON 序列化函数 `toJson()`，支持：

- string；
- number；
- boolean；
- array；
- table/object。

## 4. 生效方式

前端 TS / TSX 修改通常刷新页面即可生效。

但本次修改涉及：

- `packages/driver/boot.lua`
- `packages/driver/src/c/driver.c`

因此必须重新编译 driver wasm：

```bash
cd /opt/poe/poe1-pob-web
mise run driver:build
```

然后重启 dev server 并刷新页面。
