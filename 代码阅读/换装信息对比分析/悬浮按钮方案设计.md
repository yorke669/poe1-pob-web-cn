# 悬浮按钮方案设计

> 目标：在前端增加一个悬浮按钮，支持展开/收起、拖动位置，点击后获取计算结果并展示。

## 1. 组件结构

新增 `packages/driver/src/js/overlay/FloatingStatsButton.tsx`：

```
悬浮按钮（可拖动）
  └─ 展开面板
       ├─ 「获取计算结果」按钮
       └─ 计算结果展示区（JSON 文本 + Copy 按钮）
```

## 2. 核心功能

| 功能 | 实现方式 |
|---|---|
| **悬浮按钮** | 固定定位（`fixed`），初始位置右下角，`z-index` 高于 PoB Canvas |
| **展开/收起** | 状态 `expanded`，收起时只显示图标，展开时显示面板 |
| **拖动** | 监听 `mousedown/mousemove/mouseup`，更新 `top/left` 坐标 |
| **获取计算结果** | 调用 `driver.getBuildStats()`，结果存入 `statsJson` 状态 |
| **展示结果** | `<pre>` 显示 JSON，Copy 按钮调用 `ClipboardController` |

## 3. 样式要点

- **Tailwind 前缀**：所有 utility 必须用 `pw:` 前缀（`pw:fixed pw:bottom-4 pw:right-4`），避免与 PoB 样式冲突
- **pointer-events**：容器设 `pw:pointer-events-auto`（覆盖层默认 `none`）
- **拖动边界**：限制在视口内（`Math.max(0, Math.min(left, window.innerWidth - width))`）

## 4. 改动点清单

| 文件 | 改动 |
|---|---|

## 5. 调用时序

```
用户点击「获取计算结果」
   → driver.getBuildStats()                 (driver.ts)
   → driverWorker.getBuildStats()           (worker.ts, Comlink RPC)
   → get_build_stats() [C]                  (driver.c)
   → lua getBuildStats()                    (boot.lua)
   → JSON 字符串回传
   → FloatingStatsButton.setState({ statsJson })
   → <pre> 展示 JSON
```

## 6. 代码骨架（FloatingStatsButton.tsx）

```tsx
export function FloatingStatsButton({ driver }: { driver: Driver }) {
  const [expanded, setExpanded] = useState(false);
  const [position, setPosition] = useState({ top: 400, left: window.innerWidth - 320 });
  const [statsJson, setStatsJson] = useState<string | null>(null);
  const [dragging, setDragging] = useState(false);

  // 拖动逻辑（mousedown/mousemove/mouseup）
  // ...

  const handleGetStats = async () => {
    const json = await driver.getBuildStats();
    setStatsJson(json);
  };

  return (
    <div
      className="pw:fixed pw:z-50 pw:bg-white pw:shadow-lg pw:rounded pw:p-2"
      style={{ top: position.top, left: position.left }}
    >
      {/* 收起状态：只显示图标 */}
      {!expanded && (
        <button onClick={() => setExpanded(true)} className="pw:text-xl">
          📊
        </button>
      )}

      {/* 展开状态：面板 */}
      {expanded && (
        <div className="pw:w-80">
          <div className="pw:flex pw:justify-between pw:mb-2">
            <span>计算结果</span>
            <button onClick={() => setExpanded(false)}>✕</button>
          </div>

          <button onClick={handleGetStats} className="pw:bg-blue-500 pw:text-white pw:px-3 pw:py-1 pw:rounded">
            获取计算结果
          </button>

          {statsJson && (
            <div className="pw:mt-2">
              <pre className="pw:bg-gray-100 pw:p-2 pw:text-xs pw:overflow-auto pw:max-h-60">
                {statsJson}
              </pre>
              <button onClick={() => driver.clipboard.writeText(statsJson)}>
                Copy
              </button>
            </div>
          )}
        </div>
      )}
    </div>
  );
}
```

## 7. 依赖关系

- **前置条件**：`getBuildStats()` 接口已实现（按《读属性方案设计》）
